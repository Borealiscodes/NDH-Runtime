## Overview

The **NDH Runtime** is the spectral engine that powers adjacency physics, constellation resonance, soft‑manifold flow, guardian modulation, calm/load dynamics, and PRECL collapse.  
It is the successor to the retired SOL‑7 → SOL‑9 governed runtime layers.

The runtime is composed of four foundational artifacts:

- **Spectral Physics Primer**  
- **Spectral State Envelope**  
- **Spectral Telemetry Channels**  
- **Runtime → UI Bridge**  

These artifacts define the physics, state, telemetry, and expressive surfaces of the runtime.

## Architecture Map

### 🟩 Runtime Physics Layer  
Defines the laws governing spectral behavior:

- **Spectral adjacency**  
- **Constellation resonance**  
- **Soft‑manifold flow**  
- **Guardian modulation**  
- **Calm/load dynamics**  
- **PRECL collapse**  

Physics is runtime‑sovereign and governance‑neutral.

---

### 🟩 Runtime State Envelope  
The container for all spectral physics fields:

- adjacency field  
- resonance field  
- flow field  
- guardian modulation field  
- calm/load accumulator  
- PRECL buffer  

This envelope is reversible, altitude‑bounded, and PRECL‑collapsed.

---

### 🟩 Runtime Telemetry Channels  
Read‑only channels exposing runtime state:

- **SR‑ALT** — altitude band  
- **SR‑ADJ** — adjacency hints  
- **SR‑RES** — resonance glow  
- **SR‑FLOW** — Ballet motion hints  
- **SR‑GUARD** — guardian accents  
- **SR‑CL** — calm/load indicator  
- **SR‑PRECL** — expressive→runtime readiness  

Telemetry is humane, non‑recursive, and governance‑isolated.

---

### 🟩 Runtime → UI Bridge  
Transforms telemetry into UI‑safe signals:

- altitude indicator  
- adjacency proximity hints  
- constellation glow  
- traversal motion hints  
- guardian accents  
- runtime tension bar  
- PRECL readiness icon  

The bridge is read‑only and cannot influence runtime physics.
