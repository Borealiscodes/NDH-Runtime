# 1. Mirror Overview

The Serenity Solver Mirror is **not** a solver.  
It is a **reflection layer** that:

- mirrors solver logic  
- mirrors guardrail constraints  
- mirrors orchestration sequence  
- mirrors invariants  
- mirrors grounding coherence  
- mirrors capsule alignment  

But **never**:

- computes  
- executes  
- activates geometry  
- performs PRECL collapse  
- runs Lean, FEniCS, Rust, or any VM solver  

It is a **spectral echo**, not a computational engine.
